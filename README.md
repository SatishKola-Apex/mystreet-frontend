
# MyStreet Sneaker Store - Frontend Client
 
A responsive, modern React client application for the MyStreet E-Commerce Sneaker Store. Built with React and Vite, it delivers a seamless user experience for browsing sneaker catalogs, managing shopping carts, placing orders, and handling administrative tasks.
 
---
 
## 🚀 Tech Stack
* **React** (with Vite build tool)
* **CSS / Modern Styling**
* **Axios** for HTTP API integration
 
---
 
## 📌 Key Features
* **Product Catalog:** Browse curated sneakers with image previews, stock status, pricing in INR, and size options.
* **Shopping Cart & Checkout:** Add items, adjust quantities, select sizes, and complete orders.
* **Admin Dashboard:** Administrative capabilities to add, edit, or delete products directly from the UI.
* **User Accounts:** Modal-based login/registration workflow with persistent user state.
 
---
 
## 🛠️ Getting Started & Setup
 
### Prerequisites
* Node.js (v16+ recommended) & npm
 
### Installation & Execution
1. Clone the repository and navigate to the frontend directory.
2. Install dependencies:
   ```bash
   npm install
 
* Start the development server:
   npm run dev
 
* Open your browser and access the app at http://localhost:5173.
